# On War by Ear

Spoken scholarly lectures on Carl von Clausewitz's *On War*, rendered in the measured, elegant style of an eighteenth-century military scholar in the manner of Edward Gibbon. Built for serious study, VoiceOver, and hands-free listening.

The original Graham translation (1873) is public domain. This application offers selected chapters rephrased for clarity and period cadence, accompanied by modern reflections from the perspective of a scholar who has lost his notes yet retains foresight of later wars.

## Features
- Shuffle-ready best chapters
- Volume controls for speech and ambient layers
- Background sound suggestions (Creative Commons Napoleonic, musket, cannon, marching, horse, and ancient warfare)
- Modern commentary sections

Access via GitHub Pages once enabled. Full progressive re-translations of key books will be added. Complete Graham text: Project Gutenberg ebook 1946.
